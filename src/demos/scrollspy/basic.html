Introduction

Copy a component's HTML fragment into your project. Every interaction it needs — opening, closing, positioning — is already wired up in the markup and classes.

Install

There is no package to install. Paste the fragment, keep the classes, and the one @theme block from Getting Started supplies the tokens it references.

Tokens

Classes like bg-primary and border-border map to the same CSS variables shadcn/ui uses, so an existing theme works unchanged the moment you paste a component in.

Theming

Swap the token values and every pasted component follows — nothing in the fragments hardcodes a color, so a new palette is a handful of variable edits, not a rewrite.

FAQ

Scroll this pane, or click a link on the left — either way, exactly one heading is marked as current, and the browser is the one deciding which.
